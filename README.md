# Nozzle-1 Home Assistant Add-ons

Third-party Home Assistant add-on repository

## Add-ons

- `spoolman-tracker`: monitors supported 3D printers and updates Spoolman spool weights

## Add this repository

In Home Assistant:

1. Open `Settings` -> `Add-ons`
2. Open the `Add-on Store`
3. Use the top-right menu `Repositories`
4. Add `https://github.com/nozzle-1/hassio-addons`
